# Audit Artifact Checklist

Use this checklist to prepare evidence packages for grade reviews.

## Governance and process

- [ ] Quality policy and release authority sign-off record
- [ ] Change control and branch protection policy
- [ ] Toolchain baseline and change control record
- [ ] Risk register and mitigation status

## Requirements and traceability

- [ ] Requirements baseline with unique IDs
- [ ] Requirement to design traceability matrix
- [ ] Requirement to test traceability matrix
- [ ] Verification status by requirement criticality

## Design and architecture

- [ ] Architecture description with safety boundaries
- [ ] Interface and protocol versioning policy
- [ ] Determinism and resource budgeting rationale

## Verification and validation

- [ ] Unit, integration, and system test reports
- [ ] Soak and reliability reports
- [ ] Fault injection and resilience reports
- [ ] Performance benchmark evidence
- [ ] Coverage and static analysis reports
- [ ] Fuzz testing reports and findings

## Security

- [ ] Threat model and risk assessment
- [ ] Vulnerability scan reports and remediation log
- [ ] Security incident response records
- [ ] Cryptographic key management procedures

## Release and operations

- [ ] Release quality scorecard
- [ ] Release evidence freeze record
- [ ] Deployment and rollback procedure
- [ ] Operational monitoring and alerting evidence
- [ ] Known issues and accepted risk register

## Independent review

- [ ] Internal review sign-off
- [ ] Independent safety review checklist
- [ ] Pre-assessment readiness report and summary artifact bundle
- [ ] Pre-assessment findings log with owners and target dates
- [ ] Pre-assessment remediation plan and overdue-action summary
- [ ] External assessor findings and closure evidence
