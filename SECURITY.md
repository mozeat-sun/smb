# Security Policy

## Supported Versions

Security fixes are applied to the latest default branch.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Send a private report to the repository maintainers, including:

- Affected component and version/commit
- Reproduction steps or proof of concept
- Impact assessment
- Suggested remediation (if available)

Maintainers will acknowledge reports within 5 business days and provide a
status update after triage.

## Disclosure

We follow coordinated disclosure. Once a fix is available, we will publish
release notes describing impacted versions and mitigation steps.
