# SMB 工业级发布门禁清单

## 1. 并发稳定性门禁

- [ ] 全局发送水位与每链路发送水位同时开启时，连续压测 24 小时无崩溃
- [ ] 在高并发下无死锁、无活锁、无线程饥饿
- [ ] in-flight 指标在压力恢复后可回落到稳定区间
- [ ] 回压激活与释放日志成对出现，状态可复现

## 2. 可靠性门禁

- [ ] 传输层连续失败触发熔断，冷却后自动恢复
- [ ] 失败重试次数与配置一致，失败后错误码可追踪
- [ ] 单链路故障不引发全局发送雪崩
- [ ] 队列满、背压、熔断拒绝三类场景都有可验证用例

## 3. 安全策略门禁

- [ ] 空 sender 在 require_sender_identity 开启时被拒绝
- [ ] 未加密消息在 enforce_encrypted_messages 开启时被拒绝
- [ ] 过期消息（timestamp 超过 max_timeout）在路由入口被拒绝
- [ ] 安全拒绝计数可通过指标接口读取并与日志对账

## 4. 可观测性门禁

- [ ] 全局指标可读取：成功、失败、回压丢弃、熔断拒绝、in-flight
- [ ] 每链路指标可读取：成功、失败、回压、熔断、链路水位、链路 in-flight
- [ ] 指标重置后计数归零且不影响运行状态
- [ ] 压测报告包含 p50/p95/p99 与错误率

## 5. 回归测试门禁

- [ ] integration/test_backpressure_security 覆盖通过
- [ ] 新增每链路指标与动态水位测试通过
- [ ] 单元测试、集成测试、性能测试均可构建
- [ ] 关键路径变更均有回归记录与结果归档

## 6. 发布建议

- 先灰度发布：小流量开启每链路动态水位
- 观察 24 小时后再全量启用
- 发布后保留回滚开关：
  - 关闭 enforce_encrypted_messages
  - 关闭 require_sender_identity
  - 提高 send_high_watermark / ingress_high_watermark
